# Instagram News Extractor

A Streamlit application for extracting public Instagram posts
from a selected account within a specific date range.

## Features

- Search a public Instagram account
- Select a start and end date
- Extract posts within the selected period
- Extract:
  - Account
  - Date
  - Post type
  - Caption
  - Likes
  - Comments
  - Instagram URL
- Display results in a table
- Export results to Excel
